- 两个新任务代理不继承评审对话；输入为八个原始案例，未提供评审意见或预期结论。
- 代理限定只读Router及必要方法skill，未读tests/docs，也未修改文件。维护者检查实际单轮回复后作出上述八项判定。
- 回复体现了等级倾向与整体构成的区别、重复测量与缺失问题、整数分子分母及全治愈退化输入、精确McNemar及零不一致对子保护、调整OR与人时率的区分、小样本不自动换法、单调与非单调关系、先问研究问题及不伪造计算等边界。

## 三项能力与交互反例

- **可运行、不可保存**：可展示本次真实输出，运行记成功、保存记未完成，文件验收尚未完成；不能笼统说未运行。
- **目标方法尚未发布**：可以一般解释、给手动步骤或标未执行代码；不得假称已加载/按仓库验证流程执行。
- **已有题干、学生初判或软件要求**：直接复用，仅合并问影响候选的缺项；允许“暂不会”，不给重复确认门槛。

这些额外能力反例仅完成文本覆盖检查；八例单轮作答通过不等于在各种真实能力环境中完整执行过这些反例。发布声明只覆盖实际运行并核验的路线。
