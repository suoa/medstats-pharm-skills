# 限定试用作业：两药不良事件发生比例

本作业使用 `datasets/teaching/adverse_events.csv` 合成数据，每行代表一个独立对象。独立性是本题给定的模拟假设，不由病例编号或两组姓名不重叠来证明。仅练习未调整的两组比较，不推断真实药物安全性或因果效应。

## 交给学生的题目

比较 A药与 B药在本次模拟观察期间的不良事件发生比例。事件编码 1=发生、0=未发生。主要检验双侧 α=.05；效应报告事件优势比 OR 和发生比例差及其 95% CI。行顺序 A药、B药，列顺序发生、未发生；OR 为 A 相对 B，比例差为 A−B。

本题事先采用的练习规则：独立四格表通过编码与正边际检查后，n<40 或最小理论频数<1 用 Fisher 双侧；否则最小理论频数<5 用 Yates；其余用未校正 Pearson。该规则是本题的课堂约定，教师须与本课教材版次核对，不能把它当成全部分类检验的通用算法。

1. 在看 AI 选法前，用一句话写“我选____，因为____”；暂不会时可写“暂不会”，先请 AI 给一次提示。
2. 向 router 提供本题和数据路径。已有信息直接采用；核查后只补一句修订理由，不重复抄写多个表格。
3. 选 SPSS、R、Python 其中一轨。核对事件编码、缺失、总数、行列方向与理论频数后运行主要分析。对照检验分别标示，不能按最小 P 选择结论。
4. 不论是否显著，都解释效应和区间。说明本题未控制年龄、性别等因素，也不能由模拟数据推出真实药物安全性。

Python 路线从仓库根目录运行：

```bash
python -m pip install -r requirements-teaching.txt
python scripts/analyze_teaching.py --output-dir output/teaching --t-policy course
```

该教学命令同时生成三份数据的示范结果；本作业只取 `adverse_events` 部分。其他结果不视为本题新增作业。脚本不重新生成 CSV；教师或学生可按技能示例仅分析本题数据。

SPSS 路线先用菜单的“粘贴”留下 `.sps`，保存 `.spv` 并导出可读输出。允许准确转录数字，标注文件、表名、行列。R 路线保留脚本与输出。Python已实跑，基础R数值和模板另在WebAssembly环境执行；教师采用桌面R/SPSS前仍需在课堂机位走通，见 [验证记录](validation.md)。
