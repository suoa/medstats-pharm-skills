# 方法选择总路由（method-selection-router）

医学统计分析的**唯一入口**。任何"帮我分析/这题用什么检验/比较两组"的请求，先走本路由，再调用对应方法 skill。禁止在未确认资料类型与设计类型前直接执行检验。

## 1. 何时用

- 用户要做组间比较、显著性检验、关联性分析、回归预测，而没有明确说方法名；
- 用户说了方法名但数据条件可能不满足（例如"做个 t 检验"但结局是二分类）；
- 拿到一个新数据集，要决定从哪个方法开始。

## 2. 何时不能用

- 只是统计概念问答（"什么是 P 值"）→ 用 `result-interpretation`；
- 方法已明确且数据已核对，只需执行 → 直接进对应方法 skill；
- 高级科研分析（多水平模型、结构方程、网络 Meta 分析等超出本科医学统计大纲的内容）→ 明确告知超出本仓库范围，建议查阅专业教材或咨询统计学教师，不要硬套方法。

## 3. 执行步骤：五步定方法

### 第一步：问清或从数据读出四件事

按顺序确认，缺一不可：

1. **研究目的**：描述现状？比较组间？分析关联/回归？评价等效？
2. **结局（因变量）的资料类型**：
   - **计量资料**（定量、有单位、可连续取值，如血药浓度、含量%、血压）
   - **计数资料**（定性分类、数个数，如有效/无效、不良反应发生与否）
   - **等级资料**（有序分类，如治愈/显效/好转/无效）
3. **设计类型**：完全随机（独立组）？配对/交叉（同一对象前后或配成对子）？随机区组？
4. **组数**：1 组（与已知标准比）？2 组？≥3 组？

### 第二步：检查参数检验前提（仅计量资料组间比较时）

- 各组数据是否近似正态（Shapiro–Wilk，n<50 时必做；结合直方图/Q-Q 图）；
- 多组或两组间方差是否齐（Levene）；
- 独立 vs 配对不能搞错——这是本科考试与实操中错误率最高的一步。

前提不满足时的处置顺序：① 数据变换（如对数变换）；② 改用对应非参数方法；③ 样本量较大（经验上每组 n≥30–50）且偏度不严重时，t 检验/方差分析对非正态有稳健性，但必须在 `DECISIONS.md` 写明依据。

### 第三步：按下表路由

**A. 计量资料——比较集中趋势**

| 设计 | 组数 | 正态且方差齐 | 非正态 |
|---|---|---|---|
| 单组与已知标准比 | 1 | 单样本 t 检验 → `t-test` | 单样本 Wilcoxon 符号秩 → `nonparametric` |
| 配对/交叉 | 2（同一对子） | 配对 t 检验 → `t-test` | Wilcoxon 符号秩 → `nonparametric` |
| 完全随机 | 2 | 两独立样本 t 检验（方差齐用合并方差；不齐用 Welch）→ `t-test` | Mann–Whitney U → `nonparametric` |
| 完全随机 | ≥3 | 单因素方差分析（事后多重比较）→ `anova` | Kruskal–Wallis → `nonparametric` |
| 随机区组/配伍 | ≥3 | 随机区组方差分析 → `anova` | Friedman → `nonparametric` |

**B. 计数资料——比较率或构成比**

| 设计 | 表型 | 适用条件与方法 |
|---|---|---|
| 两独立组、二分类结局 | 2×2 四格表 | n≥40 且理论频数 T≥5：Pearson χ²；n≥40 但 1≤T<5：连续性校正 χ²；n<40 或 T<1：Fisher 精确概率 → `chi-square` |
| 两独立组、多分类结局 | R×C 列联表 | χ²（格子 T<5 不超过 1/5 且无 T<1）；不满足则合并类别或 Fisher → `chi-square` |
| 配对设计、二分类结局 | 配对四格表 | McNemar（关注不一致对子 b、c；b+c<40 用二项分布精确法）→ `chi-square` |
| 多组率、需控制混杂 | 分层/回归 | 分层 χ²/Mantel–Haenszel；多因素 → `logistic-regression` |

**C. 关联性与回归**

| 目的 | 资料条件 | 方法 |
|---|---|---|
| 两计量变量线性相关 | 双变量近似正态、线性、无极端离群点 | Pearson 相关 → `correlation-regression` |
| 两计量变量，有序等级或偏态 | 不满足 Pearson | Spearman 秩相关 → `correlation-regression` / `nonparametric` |
| 一个计量因变量 + 自变量 | 线性、独立、正态残差、等方差 | 直线/多元线性回归 → `correlation-regression` |
| 二分类结局 + 多个影响因素 | 结局 0/1，事件数/变量数足够 | 二分类 logistic 回归，报告调整 OR → `logistic-regression` |
| 时间到事件（含删失） | 有随访时间+结局指示 | Kaplan–Meier + log-rank → `survival-analysis-intro` |

**D. 描述与设计阶段**

- 只做统计描述、制表制图 → `data-types-and-summary` + `statistical-tables-graphs`；
- 开题/方案阶段算样本量、定对照与随机化 → `sample-size-design`；
- 药学专门场景（无论路由到哪一步，命中即转）：
  - 仿制药 T/R 双交叉、80–125% 界值 → `bioequivalence`；
  - 药动学参数 AUC/Cmax/Tmax 处理 → `pharmacokinetics-stats`；
  - 含量测定方法学验证（线性、精密度、回收率）→ `assay-validation`；
  - openFDA FAERS 信号、ROR → `adverse-event-analysis`；
  - 临床试验设计、终点、分析集 → `clinical-trial-stats`。

### 第四步：把决策写进 DECISIONS.md

每一次方法选择都必须落盘，格式：

```markdown
## YYYY-MM-DD HH:MM 方法选择
- 研究目的：
- 结局资料类型：
- 设计类型（含配对判定依据）：
- 组数 / 样本量：
- 前提检验结果（正态性 W、P；方差齐性 F、P）：
- 选定方法与理由：
- 若有替代方案（如 Welch / 非参数），为何不用：
```

### 第五步：进入对应方法 skill

调用该 skill 的"执行步骤"，产物（数据、输出、表、图）写入项目目录，不允许只停在对话里。

## 4. 软件执行

本 skill 是路由，不直接出统计结果。前提检查的软件命令在各方法 skill 的"软件执行"节统一给出（SPSS 菜单 | R | Python 三轨）。

## 5. 结果报告模板

路由完成时，向用户输出一段话确认，然后再执行：

> 本数据为【计量/计数/等级】资料，【独立/配对】设计，【组数】组；正态性检验 P=＿、方差齐性 P=＿，前提【满足/不满足】，因此选用【方法名】。下面按该方法执行。

## 6. 验证清单

- [ ] 研究目的、资料类型、设计类型、组数四项全部明确，无一项靠猜
- [ ] "配对还是独立"有数据结构证据（同一 ID 出现两次 / 一一对应的对子编号）
- [ ] 计量资料在参数检验前已做正态性与方差齐性检查
- [ ] 计数资料已先算理论频数再决定 χ² 公式
- [ ] 决策记录已写入 DECISIONS.md
- [ ] 已向用户说明所选方法，且未承诺"P<0.05 就说明有效/有差异"
