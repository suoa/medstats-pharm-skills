# 方法选择总路由（method-selection-router）

新数据或新研究问题先走本路由。先定问题和设计，再选择候选；不能看到两列数就直接检验。

## 1. 何时用

- 用户问“帮我分析”“比较两组”“这题用什么检验”，或需要关联、回归、预测；
- 用户指定的方法可能与结局、设计或研究目标不符；
- 研究问题、设计或分析集变化，需要更新原方法决策。

## 2. 何时不能用

- 仅问统计概念：直接解释；`result-interpretation`尚未发布时不假装调用它；
- 同一问题的方法、设计和数据已核对，只需继续执行：复用`DECISIONS.md`，不重复提问；
- 复杂交叉、多水平、结构方程等未覆盖任务：可以说明候选和准备材料，不能硬套简单检验；课程范围外或复杂设计交教师核查。

## 3. 执行步骤：五步定方法

### 第一步：从三行入口接收问题，复用已有信息

```text
题目：我想知道……（也可直接粘贴原题）
数据：附件或路径；是否同一对象测过多次？不清楚可以说明
要求：使用什么软件、教师有什么规定？未指定可说明
```

从题干、数据字典和已确认说明整理：主要结局及单位/类别顺序、希望估计的量、实验或抽样单位、设计依据、独立或相关结构、各组人数、测量时点及协变量。学生不必再填一张字段表。

只追问会改变当前候选选择的关键信息，合并询问一次；已有信息不重复确认。研究目的、随机化和独立性不能仅从列名或ID外形推定。可先给有条件的候选，再补必需信息；分类检验缺实际整数人数与分母时暂停该检验，继续数据核对。

若作业要求初判，另补“我选____，因为____”，也可写“暂不会”；AI给一次具体提示，核查后学生只补一句修订理由。初判与核查分开保留，不要求再次确认相同方法。

### 第二步：先识别设计与目标，再按资料类型分流

下列情形优先于普通“两组/多组”速查表：

| 情形 | 先处理什么 | 路由边界 |
|---|---|---|
| 同一对象≥3个时点/条件 | 对象内相关、时点、完整/缺失记录 | 重复测量候选，不能当独立ANOVA。简单完整相关样本可考虑Friedman，须核目标与假设；无覆盖skill时给一般指导 |
| 整群、批次或层级观测 | 实验单位与相关结构 | 不把同一批次的多次测定当独立重复；本仓库未提供通用层级模型流程 |
| 正式交叉、等效或非劣效 | 序列/周期、预设界值、主要参数与设计 | `bioequivalence`/`clinical-trial-stats`现为规划；不能用普通配对t或P≥0.05宣布正式BE。限定的配对对数教学演示可按`t-test`例题处理 |
| 二分类结局需控制年龄、性别等 | 调整后的目标量、编码、参照及事件信息 | ≥2组均先考虑调整模型；`logistic-regression`可作调整OR候选，不把粗χ²说成已调整，不把OR当RD/RR |
| 剂量效应或怀疑曲线 | 关联/预测/剂量反应目的，散点图与形状 | Spearman用于单调关联，不能覆盖任意曲线；非线性建模无覆盖skill时说明范围，不逐步加高次项找显著 |

### 第三步：选候选方法，再检查对应前提

**A. 计量与等级结局**

| 设计与目标 | 候选方法 | 必须核查 |
|---|---|---|
| 单组均数与已知标准比较 | 单样本t → `t-test` | 标准来源、观测独立与分布；不要求“两组方差齐” |
| 简单配对连续结局的均数差 | 配对t → `t-test` | 设计说明、按键对齐和完整对；检查差值分布，不要求两列各自正态或两组齐性 |
| 独立两组连续结局的均数差 | 合并方差或Welch t → `t-test` | 实验单位、异常值及组内分布；采用事先指定的课程或通用策略 |
| 独立≥3组连续结局 | ANOVA/Welch ANOVA或适当秩方法候选 | `anova`/`nonparametric`现为规划；不无说明地两两t，不因非正态自动更换均数目标 |
| 简单完整区组/相关样本 | 区组ANOVA或Friedman候选 | `anova`/`nonparametric`现为规划；核区组结构与模型要求，不与所有重复测量混为一谈 |
| 独立组有序结局，比较等级倾向 | 两组Mann–Whitney U；多组Kruskal–Wallis候选 | `nonparametric`现为规划；先定义类别顺序、目标及相关结构 |
| 有序结局，比较完整类别分布 | 适当列联表方法 → `chi-square` | χ²不利用顺序，须说明比较的是分布；不能写“等级资料绝不能χ²” |
| 参数法不适合或目标适于秩方法 | 符号秩、Mann–Whitney等候选 → `nonparametric` | 各有假设；单样本/配对符号秩需考虑对称性，不能当作均数检验的无条件替代 |

Shapiro–Wilk的P>0.05不能证明正态，小样本检验效力有限。小样本先核“n=8”指每组还是总共，再结合观测值、图形、异常值、设计及模型要求判断；n=8不能自动决定t或秩检验，固定总n也不能保证稳健。由对应方法skill检查其特定前提，必要时回本路由修改候选。

**B. 分类结局**

| 设计与任务 | 候选与规则 | 先核什么 |
|---|---|---|
| 独立两组二分类 | `chi-square`：按本次四格表策略选择Pearson/Yates/Fisher | 实际整数频数、分母、编码、行列顺序与全部理论频数；高治愈率仍须看少见类别，98%×30不能当29.4人 |
| 独立组多分类/整体分布 | `chi-square`：R×C Pearson或适当精确/模拟方法 | 常用近似条件为无T<1且T<5格数不超过20%；不得为显著随意合并类别；事后比较说明校正 |
| 配对二分类 | `chi-square`：McNemar | 完整/缺失对及b、c方向；课程规则可设b+c<40用双侧精确二项，≥40用指定渐近法。b+c=0先单独处理，不套除法公式 |

课程传统四格表链只用于独立两组二分类：先处理空边际；其余n<40或Tmin<1用Fisher双侧，否则Tmin<5用Yates，否则未校正Pearson。Tmin为所有格子的最小理论频数；该链是教师指定的教学策略，教材依据核查状态另记，不宣称普遍唯一。R×C和配对表不进入该链。

建表前核编码、非负整数与总数，不静默丢弃未知类别。任一空行/列边际时，本次教学实现只描述可定义的频数和率，不硬算Pearson/Yates或Wald OR区间；空样本组的率写“不适用”。孤立零格而边际均正与空边际不同，可按所选规则考虑Fisher；OR可能为0、无穷或未定义，不偷偷加0.5。

**C. 关联、描述、设计与药学专门任务**

- 线性关联→Pearson候选；单调关联→Spearman候选；回归按模型检查残差与设计，不能用“非正态就Spearman”代替目的辨识。`correlation-regression`现为规划。
- 描述/图表→`data-types-and-summary`、`statistical-tables-graphs`；样本量/随机化→`sample-size-design`；随访删失→`survival-analysis-intro`，现均为规划，可提供一般说明。
- AUC/Cmax/Tmax处理、方法学验证、FAERS信号与临床试验分别对应规划中的`pharmacokinetics-stats`、`assay-validation`、`adverse-event-analysis`、`clinical-trial-stats`。名称命中不等于方法已实现；以实际可读且覆盖任务的文件为准。

### 第四步：锁定本次规则，简记决策

查看主要检验结果前记录一行：“采用【教师指定课程规则/通用预设策略】，软件【及版本】，主方法/决策规则【____】，方向【谁减谁/谁相对谁】。”课程可保留Levene分流和传统四格表链；通用独立两组分析可事先选Welch。需诊断后分流时先写规则，再记实际选行；不得按较小P改规则、方法或软件。

将问题、目标、实验单位/设计依据、实际方法及一句理由写入`DECISIONS.md`；诊断只记适用项目，不适用写明。学生不重复抄到LOG，后者记录实际操作与文件来源。配对数据按键核唯一性、对齐后取完整对，不分别删缺失再按行拼接。

### 第五步：检查方法覆盖与环境能力，诚实继续或降级

- 关键缺项：合并询问，继续不依赖答案的核对；不能自创研究问题或遍历变量寻找显著。
- 目标skill未发布/不可读/不覆盖：说明候选、理由和缺口；不声称已加载或按本仓库已验证流程执行。仍可给一般解释、手动步骤或标为未执行的代码；复杂设计交教师核查。
- 能运行但不能保存：可呈现本次真实输出，写“已计算，尚未保存，未完成作业文件验收”。不能运行：只给未执行指导，不填造统计结果。
- 读取、运行、保存、核验分别记实；部分成功不等于全部完成。输入足够、方法覆盖且能力具备后继续执行，无需再问“是否确认采用”。

维护者可使用`R01_INPUT_REQUIRED`、`R02_SKILL_UNAVAILABLE`、`R03_EXECUTION_UNAVAILABLE`、`R04_REVIEW_REQUIRED`（方法争议待教师核查）和`READY`（具备执行条件）。先补影响候选的关键输入，再查方法覆盖、未解决争议和执行能力；这些标签不要求学生学习，`READY`不表示已经运行通过。

## 4. 软件执行

本skill负责路由，不直接计算统计量。所选方法的SPSS菜单、R或Python步骤见其软件执行节；单份作业只需采用教师指定或事先选定的一轨。贴入Markdown不会自动提供读数据、运行软件或保存文件的能力。

记录实际软件版本与过程。SPSS可用菜单“粘贴”保存`.sps`，保留`.spv`及可读PDF/其他导出；报告允许准确转录，注明表名、行列或页码。脚本路线保留代码、运行日志及结果文件。未实跑轨道标“未执行/待验证”，不称三轨均通过。

## 5. 结果报告模板

路由完成后说明并继续，不追加形式性确认：

> 要回答【问题】，结局为【变量/类型】，设计依据是【题干/方案及相关结构】；本次采用【规则】，候选/选定【方法】，方向【____】。仍需【缺项或方法特定检查；无则写无】。读取/运行/保存/核验状态【分别记实】，下一步【具体动作】。

缺少输入时不填P；尚未运行时不写结果。报告数字来自本次实际输出，不以例题答案代替。P≥0.05不等于无差别或等效，专业重要性需有专业依据。

## 6. 验证清单

- [ ] 复用题干和已有回答，仅合并追问影响选择的关键缺项
- [ ] 研究目的、目标量、实验单位与相关结构有依据，未从列名或ID猜设计
- [ ] 重复测量、整群、正式交叉、等效/非劣效及调整需求已先辨识
- [ ] 候选方法检查对象正确；未以SW非拒绝证明正态，未统一要求所有参数法方差齐
- [ ] 分类人数与分母有效；空边际、零格、配对不一致对子及方向已分别处理
- [ ] 本次课程/通用规则和方向在看主要结果前记录，未按较小P换法
- [ ] 目标skill发布/可读/覆盖状态真实，未将普通指导说成已验证流程
- [ ] 读取、运行、保存、核验分别记实，报告数字可追溯到本次实际输出
- [ ] 学生初判允许“暂不会”，保留一次修订理由，无重复确认或重复抄写负担
