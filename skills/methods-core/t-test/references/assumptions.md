# t 检验前提条件详解（references/assumptions）

SKILL.md 的展开材料。学生问"为什么要做正态性检验""P=0.049 算不算正态"时读这里。

## 一、独立性（三类 t 检验共同的前提）

- 观测之间相互独立：一个受试者的结果不影响另一个；抽样/分组过程带随机化。
- 配对 t 要求"对子之间独立"，不要求两组独立——同一对子内的两个值本来就相关。
- 常见违反：同一批动物重复测多次当成多个样本；整群抽样按个体分析。本科实验中一旦出现"重复测量"字样，退回路由器重新定方法。

## 二、正态性

### 检验对象（最容易错）

| 方法 | 检验正态性的对象 |
|---|---|
| 单样本 t | 原始观测值 |
| 配对 t | **差值 d**（不是两组原始值各自正态） |
| 独立样本 t | 两组各自的观测值 |

### 可用工具

- Shapiro–Wilk：n 在约 3–50 时首选，n 过大时会对微不足道的偏离也报显著，反而不宜单靠它；
- 图形：直方图、Q-Q 图（教学中推荐与检验并列，培养目测能力）；
- 偏度/峰度仅作参考。

### 判定与处置

1. P>0.05 且图形无明显偏态/离群 → 满足；
2. 轻度偏离 + 每组 n 较大（经验上 ≥30，独立 t 可放宽到合计较大）→ t 检验稳健，照常使用，在 DECISIONS.md 注明依据；
3. 明显偏态或小样本严重偏离 → 先考虑数据变换（对数变换常用于浓度类右偏数据，如 Cmax、AUC），变换后重做正态性检查；
4. 变换无效 → 非参数方法（符号秩 / Mann–Whitney U）。

### 教学提醒

- 正态性检验 P=0.052 与 P=0.048 在证据强度上几乎没有差别，不要把 0.05 当成悬崖；结合图形、样本量和专业背景判断，并把判断写进 DECISIONS.md。
- 离群值先查录入错误和实验事故，不能"为了显著"删数据；保留时做含/不含离群值的敏感性分析。

## 三、方差齐性（仅独立样本 t）

- Levene 检验（软件里也可能给 Brown–Forsythe，结论用法相同）；
- P>0.05 → 合并方差 t（pooled）；
- P≤0.05 → Welch t。两组样本量相等时方差不齐影响较小，样本量不等时影响大，但本科统一按检验结果选，避免学生记例外；
- SPSS 独立样本输出表一次给出两行结果，按 Levene 行选择读哪一行——这是实验课最常见的读图错误点。

## 四、前提检查的最小代码块（Python）

```python
from scipy import stats

# 独立样本
for name, g in [("A", a), ("B", b)]:
    w, p = stats.shapiro(g)
    print(name, "Shapiro W=%.3f P=%.3f" % (w, p))
F, pL = stats.levene(a, b, center="mean")
print("Levene F=%.3f P=%.3f" % (F, pL))

# 配对：对差值做
d = x_t - x_r
w, p = stats.shapiro(d)
print("差值 Shapiro W=%.3f P=%.3f" % (w, p))
```

## 五、决策速查

```
计量资料，1–2 组均数比较
├── 1 组 vs 标准值 ── 观测值正态？──是──▶ 单样本 t
│                              └─否─▶ 符号秩
├── 配对/交叉 ────── 差值正态？──是──▶ 配对 t（浓度先取对数）
│                              └─否─▶ Wilcoxon 符号秩
└── 独立两组 ── 各组正态？
        ├──是── Levene 齐？──齐──▶ 合并方差 t
        │                    └不齐▶ Welch t
        └──否（且不满足大样本稳健条件）──▶ Mann–Whitney U
```
