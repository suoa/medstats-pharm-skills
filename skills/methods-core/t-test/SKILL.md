# t 检验（t-test）

对 1–2 组计量资料的均数进行比较的参数方法。**进入本 skill 前必须已完成方法选择路由**；若资料类型、配对关系或正态性未确认，退回 `method-selection-router`。

## 1. 何时用

| 类型 | 典型问法 | 数据结构 |
|---|---|---|
| 单样本 t | 这批片重是否等于标示值？实测均值是否与理论值不同？ | 一列观测值 + 一个已知标准 μ₀ |
| 配对 t | 同一批受试者服药前后？T/R 交叉制剂？配成对子的两个样本？ | 每行一对（同 ID / 对子号），先算差值 d |
| 两独立样本 t | 两种工艺、两个剂量组、两个病区样本的均数比较？ | 分组列 + 结局列，两组个体不重叠 |

## 2. 何时不能用（前提与禁忌）

1. **结局不是计量资料**（有效/无效之类的二分类结局）→ 卡方或 Fisher，见 `chi-square`；
2. **严重非正态**（尤其小样本 n<30、明显偏态或有极端离群值）→ 非参数方法（Wilcoxon 符号秩 / Mann–Whitney U），见 `nonparametric`；
3. **三组及以上**仍两两做 t 检验 → 禁止，属多重比较问题，用方差分析 + 事后比较，见 `anova`；
4. **把配对数据当独立样本做**，或反之 → 方法全错。判定依据只能是数据结构，不是口头描述；
5. 两独立样本方差不齐时用合并方差 t → 改用 Welch t；
6. 独立样本要求组间独立、组内观测独立（不能把重复测量当独立样本）；
7. 离群值不得直接删除；先核对数据录入，再用敏感性分析（含/不含离群值对比）并写入 DECISIONS.md。

## 3. 执行步骤

### 3.0 通用准备

1. 从 `data/raw/` 读取原始数据，复制到 `data/clean/` 再处理；原始文件只读不改；
2. 核对样本量、缺失值、单位；连续变量缺失记录数量与处理方式（本科默认不插补，按可用病例分析并注明）；
3. 在 `DECISIONS.md` 记录方法选择（资料类型、配对判定、正态性/方差齐性结果）。

### 3.1 单样本 t

- 计算 x̄、s、n；
- 前提：观测独立、近似正态（n 小时做 Shapiro–Wilk）；
- 统计量 t = (x̄ − μ₀) / (s/√n)，df = n−1；
- 给出均数与 μ₀ 之差的 95% CI、Cohen's d（可选）。

### 3.2 配对 t

- 逐对算差值 d = X₁ − X₂（**顺序必须固定并写明**，如 T−R 还是 R−T）；
- 检查对象是**差值的正态性**，不是两组原始数据各自正态；
- t = d̄ / (s_d/√n)，df = n−1；
- 给出差值均数的 95% CI；
- **交叉试验 Cmax/AUC**：先对两个序列各自取自然对数再算差值，见 references/examples.md「生物等效性」。差值不拒绝 0（P>0.05）**不等于**等效；等效判定走 `bioequivalence` skill 的 90% CI 界值法。

### 3.3 两独立样本 t

1. 分组描述：n₁、x̄₁、s₁ 与 n₂、x̄₂、s₂；
2. 两组各自正态性检验（Shapiro–Wilk）+ 直方图/Q-Q 图；
3. Levene 方差齐性检验：
   - P>0.05 视为方差齐 → 合并方差 t，df = n₁+n₂−2；
   - P≤0.05 → Welch t，自由度按 Welch–Satterthwaite 校正（软件自动算）；
4. 给出均数差（写明谁减谁）的 95% CI、Cohen's d（均数差/合并标准差）；
5. 输出写入 `output/`（表 + 文本结果），图写入 `output/figures/`。

### 3.4 收尾

- 在 LOG.md 记录一行：时间、数据文件、方法、关键结果文件路径；
- 报告中每个数字必须能在 `output/` 的结果文件中找到。

## 4. 软件执行（三轨）

三轨等价，教学环境有哪套用哪套。结果数字必须来自软件实际输出，不得手算后誊写。

### 轨 A：SPSS（菜单路径）

- 单样本：`分析 → 比较平均值 → 单样本 T 检验`，检验值填 μ₀；
- 独立样本：`分析 → 比较平均值 → 独立样本 T 检验`；分组变量定义组值；输出表同时给 Levene 与两行 t（合并方差 / Welch），按 Levene 结果读对应行；
- 配对样本：`分析 → 比较平均值 → 配对样本 T 检验`，选入成对变量；
- 正态性：`分析 → 描述统计 → 探索`，绘图勾选"含检验的正态图"（输出 Shapiro–Wilk）。

### 轨 B：R

```r
# 单样本
t.test(x, mu = mu0)
# 配对（数据为同序两列 pre, post）
t.test(dat$post, dat$pre, paired = TRUE)
# 独立样本（长表：group, value）
with(dat, t.test(value ~ group, var.equal = FALSE))  # Welch（默认）
car::leveneTest(value ~ group, data = dat)           # 方差齐性
shapiro.test(dat$value[dat$group == levels(dat$group)[1]])
```

### 轨 C：Python（scipy / statsmodels，推荐脚本化，产物可复跑）

```python
from scipy import stats
# 单样本
stats.ttest_1samp(x, popmean=mu0)
# 配对
stats.ttest_rel(x_t, x_r)
# 独立样本：equal_var=False 为 Welch；True 为合并方差
stats.ttest_ind(a, b, equal_var=False)
stats.levene(a, b, center="mean")       # Levene
stats.shapiro(a)                        # Shapiro–Wilk（n≤50 左右适用）
```

完整可运行示例与数据路径见 references/examples.md。

## 5. 结果报告模板

- **单样本**：含量测定 n=＿，x̄±s=＿±＿%，与标示量 100% 比较，t(df)=＿，P=＿；均数差 95%CI（＿，＿）。
- **配对**：服药后与服药前比较，差值 d̄=＿（95%CI：＿～＿），t(＿)=＿，P=＿，可认为服药前后差异有/无统计学意义。
- **独立样本**：A 组 n=＿、x̄±s=＿±＿，B 组 n=＿、x̄±s=＿±＿；Levene 检验 P=＿，方差齐/不齐，采用合并方差/Welch t 检验，t(＿)=＿，P=＿；均数差（B−A）=＿，95%CI（＿，＿），Cohen's d=＿。

书写纪律：
- 先给描述统计（n、x̄±s），再给检验结果，最后给效应量与专业解释；
- 写"差异有/无统计学意义"，不写"有/无显著性差异"之外的随意表述；P 值给确切值（P=0.024），P<0.001 才写 P<0.001；
- 统计结论之后必须有**专业结论**，且二者可能不一致（见例题 2：P<0.05 但差异 0.76 个百分点无药学意义）。
