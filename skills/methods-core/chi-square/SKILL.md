# χ² 检验（chi-square）

对计数资料比较率或构成比的方法。**进入本 skill 前必须已完成方法选择路由**；如果数据是等级资料或目的是分析影响因素，退回 `method-selection-router`。

## 1. 何时用

| 设计 | 表型 | 方法 |
|---|---|---|
| 两独立组，二分类结局 | 2×2 四格表 | Pearson χ² / 连续性校正 χ² / Fisher（按适用条件链选） |
| ≥2 个独立组或结局多分类 | R×C 列联表 | Pearson χ²（必要时合并类别或 Fisher） |
| 配对设计，二分类结局 | 配对四格表 | McNemar |
| 多组率趋势（按剂量/年龄有序） | 2×k | 线性趋势 χ²（选讲，教师可跳过） |

## 2. 何时不能用（前提与禁忌）

1. **等级资料用 χ² 比构成比**——χ² 只利用类别的频数、丢弃次序信息。治愈/显效/好转/无效这类结局 → 秩和检验，见 `nonparametric`；
2. **结局是计量资料**（浓度、含量%）→ t 检验或方差分析，不能把连续值人为分两组后做 χ²（损失信息，且分组切点操纵结果）；
3. 适用条件不满足时硬算普通 Pearson χ²（见第 3 节条件链）；
4. R×C 表 χ² 显著后直接说"各组率两两不同"——只能说"不全相同"，两两比较需分割表并校正 α；
5. 把配对四格表当独立四格表（同一批对象前后/两种方法测同一标本）；
6. 多中心/分层数据只做粗 χ²、不考虑中心效应（本科可提示局限性，多因素分析见 `logistic-regression`）。

## 3. 执行步骤

### 3.1 先汇总成列联表，再算理论频数

- 原始数据保留一行一个体（分组列 + 0/1 结局列），列联表由软件交叉汇总生成，不允许只保留手算频数表后丢掉原始数据；
- 每个格子的理论频数 T_rc = (第 r 行合计 × 第 c 列合计) / 总例数。

### 3.2 四格表适用条件链（本科必须按顺序判断）

```
总例数 n ≥ 40？
├── 是 ── 所有格子 T ≥ 5？
│         ├── 是 ──────────── Pearson χ²（不校正）
│         └── 否，有 1 ≤ T < 5 ── 连续性校正 χ²
│                   └── 若有 T < 1 ── Fisher 精确概率
└── 否（n < 40）──────────── Fisher 精确概率
```

记忆口径：**n≥40 且 T≥5 用普通卡方；n≥40 但有 T 在 1～5 之间用校正；n<40 或 T<1 用 Fisher。**

### 3.3 R×C 列联表

- 条件：T<5 的格子数不超过总格子数的 1/5，且没有 T<1 的格子；
- 不满足时：① 合理合并类别（专业上可合并才能合）；② 增加样本量；③ Fisher–Freeman–Halton 精确检验；
- 结局多分类且关心"构成比是否相同"，用法同；自由度 df=(R−1)(C−1)。

### 3.4 配对四格表（McNemar）

同一批 n 个对象两种处理/两个时点的二分类结果：

| | B 阳性 | B 阴性 |
|---|---|---|
| **A 阳性** | a（一致） | b |
| **A 阴性** | c | d（一致） |

- 只看不一致对子 b、c；H₀：B=C；
- b+c≥40：χ² = (b−c)²/(b+c)；
- b+c<40：用二项分布精确法（教材称校正公式 χ²=(|b−c|−1)²/(b+c) 为过渡口径，教学中可并列介绍，软件精确法优先）。

### 3.5 效应量与置信区间（显著之后必须给）

- 率差 RD = p₁−p₂，给出 95% CI；
- 四格表报告 OR = ad/bc 及 95% CI（横断面/队列研究也可报 RR，按研究设计区分，OR≠RR，结果率高时差异很大）；
- 报告各组率的实际数值（如 20.0% vs 6.7%），不能只报 χ² 和 P。

### 3.6 落盘

- 交叉表、检验输出写入 `output/`（建议同时保存 .csv 表与文本结果）；
- DECISIONS.md 记录适用条件链的判断（n、最小理论频数、选用公式）；LOG.md 记一行流水。

## 4. 软件执行（三轨）

### 轨 A：SPSS

- `分析 → 描述统计 → 交叉表`；行放分组、列放结局；
- "统计"勾选**卡方**、风险（出 OR 及 95%CI）；
- "单元格"勾选观测数、期望值（理论频数）、行百分比；
- 输出脚注会直接提示"有多少个格子期望计数小于 5"以及最小期望计数——按脚注选 Pearson 行/连续性校正行/Fisher 行；
- McNemar：同样进交叉表，"统计"勾选 **McNemar**（SPSS 对 2×2 自动给二项精确）。

### 轨 B：R

```r
tab <- table(dat$drug, dat$adverse_event)
chisq.test(tab, correct = FALSE)   # Pearson
chisq.test(tab, correct = TRUE)    # 连续性校正
fisher.test(tab)                   # Fisher + OR 的 CI
mcnemar.test(tab_paired)           # 配对四格表
# 理论频数
chisq.test(tab, correct = FALSE)$expected
```

### 轨 C：Python

```python
import pandas as pd
from scipy import stats

df = pd.read_csv("datasets/teaching/adverse_events.csv")
tab = pd.crosstab(df.drug, df.adverse_event)
chi2, p, dof, expected = stats.chi2_contingency(tab, correction=False)
chi2c, pc, _, _ = stats.chi2_contingency(tab, correction=True)
odds, pf = stats.fisher_exact(tab)
print(expected)   # 先看理论频数再决定用哪个 P

# McNemar（配对四格表，scipy 不含，用 statsmodels）
from statsmodels.stats.contingency_tables import mcnemar
mcnemar([[a, b], [c, d]], exact=True)   # b+c<40 时用 exact=True
```

## 5. 结果报告模板

- **四格表**：A 组不良反应发生率为 ＿%（＿/＿），B 组为 ＿%（＿/＿）；总例数 n=＿，最小理论频数 T=＿，满足/不满足 χ² 条件，采用 Pearson χ²/连续性校正/Fisher 精确检验，χ²=＿，df=1，P=＿；OR=＿（95%CI：＿～＿）。
- **R×C**：＿组有效率分别为 ＿、＿、＿，χ²(df)=＿，P=＿，可认为各组有效率不全相同；两两比较（Bonferroni 校正 α=＿）结果为……。
- **配对**：两种方法阳性率分别为 ＿、＿，不一致对子 b=＿、c=＿（b+c＿40），McNemar 检验 P=＿。

书写纪律：
- 先给率和实际频数，再给条件判断，再给统计量与效应量；
- 率保留 1 位小数，χ² 与 OR 保留 2–3 位小数，P 给确切值；
- 结论句式："可认为两药不良反应发生率的差异有统计学意义"，不写"两药有差异"这种把率差偷换成药物整体差异的说法；
- 观察性数据（非随机分组）只能报告关联，不能写"导致/引起"。
