# 教学数据集（teaching datasets）

本目录所有数据均为**教学模拟数据**，不含任何真实受试者信息。CSV 由 `generate_datasets.py` 以固定随机种子（20261017）生成，任何人重跑得到完全相同的文件。

重跑方式：

```bash
python3 generate_datasets.py
```

参考答案（统计量、P 值、置信区间）由脚本实跑写入 `reference_outputs.txt`。skill 正文中的例题数字一律以该文件为准，禁止手工改写。

## 1. bioeq_cmax.csv — 生物等效性交叉试验

**背景**：24 名健康受试者参加某仿制药双周期双交叉生物等效性试验，分别服用受试制剂 T 与参比制剂 R，测定血药峰浓度 Cmax（ng/mL）。

| 变量 | 类型 | 说明 |
|---|---|---|
| `subject_id` | 标识 | 受试者编号 S01–S24 |
| `cmax_R` | 计量 | 参比制剂 R 的 Cmax（ng/mL） |
| `cmax_T` | 计量 | 受试制剂 T 的 Cmax（ng/mL） |

**配套方法**：配对 t 检验（在**对数尺度**上对 ln(T) 与 ln(R) 做配对 t）；几何均值比 GMR 及其 90% CI。

**教学要点**：
- 配对设计先算差值：差值 = ln(Cmax_T) − ln(Cmax_R)；
- 生物等效性的判定是 GMR 的 **90% CI 完全落在 80.00%–125.00%**，不是"差异检验 P>0.05"；
- 本数据中配对 t 检验 P=0.54（不拒绝相等），而 90% CI 为 (93.06%, 103.41%)，仍可判定等效——说明"无统计学差异"与"证明等效"是两件事；
- 为什么取对数：Cmax 右偏、个体间差异大，对数转换后差值近似正态，且界值 80–125% 在对数尺度上关于 0 对称。

## 2. tablet_assay.csv — 两种制片工艺的含量测定

**背景**：两种制片工艺各随机抽取 20 片进行含量测定，结果以相当于标示量的百分比（%）表示。药典含量限度通常为标示量的 95.0%–105.0%。

| 变量 | 类型 | 说明 |
|---|---|---|
| `tablet_id` | 标识 | 片剂编号（A01–A20，B01–B20） |
| `process` | 分组 | `A_对照工艺` / `B_新工艺` |
| `assay_pct` | 计量 | 含量相当于标示量的百分比（%） |

**配套方法**：独立样本 t 检验（Shapiro–Wilk 正态性、Levene 方差齐性）；均数差 95% CI；Cohen's d。

**教学要点**：
- 独立两样本先分清"独立"还是"配对"（本数据两组各 20 片，无配对关系）；
- 本例 t=2.339、P=0.025，达到 α=0.05 显著，但均数差仅 0.76 个百分点，两组均在药典限度内——**统计显著不等于专业上有意义**；
- 反之也要让学生看到：样本量增大后小差异会变"显著"，P 值不能代替效应量。

## 3. adverse_events.csv — 两种药品的不良反应发生情况

**背景**：两种药品各 120 例用药记录，观察某不良反应是否发生。

| 变量 | 类型 | 说明 |
|---|---|---|
| `subject_id` | 标识 | 病例编号（PA001–PA120，PB001–PB120） |
| `drug` | 分组 | `A药` / `B药` |
| `adverse_event` | 计数（二分类） | 1=发生，0=未发生 |

**四格表**：A 药 24/120（20.0%），B 药 8/120（6.7%）。

**配套方法**：四格表 χ² 检验（总 n=240≥40，四个理论频数均为 16 或 104，全部 ≥5，用普通 Pearson χ²）；报告 OR 及 95% CI；可同时算连续性校正 χ² 与 Fisher 精确检验作对照。

**教学要点**：
- 先过适用条件链再选公式：n≥40 且理论频数 T≥5 → 普通 χ²；n≥40 但有 1≤T<5 → 连续性校正；n<40 或 T<1 → Fisher；
- 原始记录是一行一个病例（长表），交叉表由软件汇总，不要手算频数后丢原始数据；
- χ² 显著只说明率不全相同，差异大小要看率差与 OR（本例 OR=3.50，95% CI 1.50–8.15）。

## 数据集扩充约定

新增数据集时：
1. 数据生成逻辑写进 `generate_datasets.py`（或新增带固定种子的脚本），不允许只上传无生成方式的 CSV；
2. 在本 README 补：背景、变量字典、配套方法、教学要点；
3. 真实数据只能使用已公开发表、许可清晰的数据，并注明出处；含任何受试者信息的真实数据不得入库（脱敏也不行，本科教学一律用模拟或公开汇总数据）。
