# 通用对话、提示词与知识库导入

不能使用原生技能目录时，可把Markdown作为指令与参考资料提供给agent。此方式不保证自动发现、完整检索、代码执行或文件保存。

## 提供本题所需内容

- 给出router、本次方法的`SKILL.md`及所需`references/`；知识库只检索出片段时，核对关键前提和例题是否实际读到。
- 保留文件名与引用关系。不能上传目录的平台逐文件上传；不把“已上传”当“agent已完整读取”。
- 题目、数据位置和教师要求已有则复用，不重复填表；学生入口见[安装说明](README.md)。

可用指令：

> 先依据method-selection-router整理本题的问题、目标与设计，再读取所选方法及必要参考。仅合并追问影响选择的缺项。说明实际可读取、运行和保存的内容；未执行的步骤和代码明确标记。方法未发布时可一般答疑，不声称其仓库流程已验证执行。

## 按真实能力继续

- 仅可对话：提供手动菜单步骤或“未执行”的代码，不填写虚构结果。
- 可实际计算但不能保存：可以展示本次真实输出，注明“已计算，尚未保存，未完成作业文件验收”。
- 可运行并保存：保留本次代码/语法、软件版本与输出，核对后引用结果。读取、运行、保存、核验分别记实。

SPSS学生可自行运行、保存`.sps`/`.spv`及可读导出，再让agent核对；允许准确转录并标明表名/行列。AI不能看到的输出不假称已经核验。原始数据不覆盖，上传前按教师及学校要求处理；教学优先使用配套合成数据，见[SECURITY.md](../SECURITY.md)。

核查范围（2026-10-18）：以上为通用指令输入方式，本次未逐一实测Coze、Dify、GPTs或其他平台，不承诺它们都具备原生skills或执行能力。
