# 通用导入（扣子等平台型 agent）

大多数平台型 agent（扣子 Coze、Dify、GPTs、智能体编辑器等）虽然没有"本地技能目录"概念，但都能用下面任一方式吃进 skill 约定：

## 方式 1：知识库

1. 把 skill 目录（SKILL.md + references/）上传为知识库文件；
2. 在智能体提示词中写：
   > 处理医学统计分析任务时，先检索并严格遵循知识库中的方法约定；方法不确定时先执行 method-selection-router 的五步法。
3. 开启按需检索，避免一次性占满上下文。

## 方式 2：提示词

把 method-selection-router 的 SKILL.md 全文放进系统/人设提示词；具体方法 skill（t-test、chi-square 等）作为知识库或按需粘贴。

## 方式 3：对话内引用

学生在对话里直接附上 SKILL.md 文件，说「按这个文件的约定做」。零配置，课堂演示最快。

## 注意

- 平台上传数据前先确认数据合规（见 SECURITY.md），课堂练习用仓库自带的合成数据；
- 让 agent 把代码与输出保存为文件，不要停留在对话框里——这是本仓库的核心约定。
