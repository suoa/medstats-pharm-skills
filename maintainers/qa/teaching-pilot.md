# 限定试用作业：两药不良事件发生比例

本作业使用 `datasets/teaching/adverse_events.csv` 合成数据，每行代表一个独立对象。独立性是本题给定的模拟假设，不由病例编号或两组姓名不重叠来证明。仅练习未调整的两组比较，不推断真实药物安全性或因果效应。

## 交给学生的题目

比较 A药与 B药在本次模拟观察期间的不良事件发生比例。事件编码 1=发生、0=未发生。主要检验双侧 α=.05；效应报告事件优势比 OR 和发生比例差及其 95% CI。行顺序 A药、B药，列顺序发生、未发生；OR 为 A 相对 B，比例差为 A−B。

本题事先采用的练习规则：独立四格表通过编码与正边际检查后，n<40 或最小理论频数<1 用 Fisher 双侧；否则最小理论频数<5 用 Yates；其余用未校正 Pearson。该规则是本题的课堂约定，教师须与本课教材版次核对，不能把它当成全部分类检验的通用算法。

1. 先用一句话写“我选____，因为____”；暂不会时可写“暂不会”，再按本课规定向教师、讲义或AI取一次具体提示。已有初判须保留，修订只补一句理由。
2. 按课程要求或自己选择使用AI时，在获准环节向 router 提供本题和数据路径；已有信息直接采用。不使用AI时，按教材和教师指引完成同样的问题、设计、编码与条件核查，在`DECISIONS.md`核查来源中注明“未使用AI”，不要求调用router。AI为可选时，不因没有AI记录判为缺交；教师明确要求的课后AI任务仍须按题单另外完成。正课禁用、课后允许时，先完成课堂任务，再进入指定课后环节。
3. 只用教师指定或允许的一轨。核对事件编码、缺失、总数、行列方向与理论频数后运行主要分析。对照检验分别标示，不能按最小 P 选择结论。
4. 不论是否显著，都解释效应和区间。说明本题未控制年龄、性别等因素，也不能由模拟数据推出真实药物安全性。

Python 路线从仓库根目录运行：

```bash
python -m pip install -r maintainers/requirements-teaching.txt
python maintainers/scripts/analyze_teaching.py --output-dir output/teaching --t-policy course
```

该教学命令同时生成三份数据的示范结果；本作业只取 `adverse_events` 部分。其他结果不视为本题新增作业。脚本不重新生成 CSV；教师或学生可按技能示例仅分析本题数据。

共用Python命令要求输出目录尚不存在，已有空目录也拒绝。重跑另设`--output-dir`并同步读取和报告路径，保留上一轮输出；不把保存失败的运行记为文件验收完成。

SPSS 路线先用菜单的“粘贴”留下 `.sps`，保存 `.spv` 并导出可读输出。允许准确转录数字，标注文件、表名、行列。R 路线保留脚本与输出。Python已实跑，基础R数值和模板另在WebAssembly环境执行；教师采用桌面R/SPSS前仍需在课堂机位走通，见 [验证记录](validation.md)。

教师可先生成[SPSS机房验收包](spss-machine-check.md)，本作业对应其中`03_adverse_events.sps`。包中参考值不能算学生或教师的SPSS实测；填写运行记录并保留本次SPV/PDF后，才记录实际通过的项目。
