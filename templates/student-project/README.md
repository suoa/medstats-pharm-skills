# 学生分析项目模板

每份作业复制整个目录并重命名。先按教师要求选一种软件，不要求同时学SPSS、R、Python。

## 最小入口

```text
题目：我想知道……（也可直接粘贴原题）
数据：附件或路径；是否同一对象测过多次？不清楚可以说明
要求：使用什么软件、教师有什么规定？未指定可说明
```

已提供的信息直接采用。若作业要求初判，另写“我选____，因为____”或“暂不会”；核查后只补一句修订理由。提示可来自教师、讲义或课程允许的AI；不使用AI时，核查来源注明“未使用AI”，不要求调用skill。AI为可选时不因未使用而判缺交；教师明确要求的课后AI任务仍按题单完成。课堂和课后AI范围以具体作业为准。

## 目录结构

```text
data/raw/    原始数据，只读
data/clean/  清洗后的数据及处理记录
output/      本次统计输出、图及运行记录
report/      报告
DECISIONS.md 问题、方法和一句理由
LOG.md       实际操作、版本、文件来源与完成状态
```

## 开始分析

1. 原始数据放`data/raw/`，保留原件。清洗后另存`data/clean/`；用脚本或SPSS“粘贴”语法记录处理，不覆盖原始数据。
2. 按课程要求或自己选择使用AI时，在获准环节用`method-selection-router`整理问题与设计；不用AI时，按教材和教师指引完成同样的核查。已有决策只补缺，不重复确认；规划中的skill不能声称已加载执行，仍可提供一般指导。
3. 查看主要检验结果前，一行写清课程/通用规则、软件、主方法或分流规则及比较方向；不按较小P换方法。
4. 执行一轨并保留真实输出。SPSS保存`.sps`、`.spv`及可读导出；脚本路线保留代码、软件版本和结果文件。
5. 按本课教材/教师核对表核验；允许AI时可用方法skill辅助，再写自己的解释。每个数字须追溯到本次输出；允许准确转录SPSS数字并标表名/行列，不能凭记忆补数或照抄参考答案。

## 学生与教师各记录什么

学生最少交“问题、方法及一句理由、真实输出来源、结果解释”。`DECISIONS.md`与`LOG.md`复用同一信息，不重复抄写；版本与参数可由教师模板或实际输出带入。模板空格不是要求每份作业填满所有方法。

读取、运行、保存和核验分别记实。能计算不能保存时可展示本次真实输出，标“已计算，尚未保存，未完成作业文件验收”；不能运行时只交未执行指导，不造结果。最终文件验收仍须能找到原始数据、实际步骤与输出。
