# 学生分析项目模板

每次统计作业/实验新建一个这样的目录。把模板整个复制到你自己的文件夹，重命名为作业名。

## 目录结构

```
data/
  raw/        原始数据，只读。从老师那里拿到什么样就存什么样，永远不改
  clean/      清洗后的数据（清洗脚本生成，不手工改）
output/       代码运行产物：结果表、图、日志
report/       实验报告
DECISIONS.md  方法决策记录（选了什么方法、为什么、前提检查结果）
LOG.md        操作流水（谁、何时、跑了什么、发现了什么）
```

## 三条硬性约定

1. `data/raw/` 里的文件**只读**，清洗一律写脚本，产物放 `data/clean/`；
2. 报告正文每个统计数字必须来自 `output/` 中的文件，禁止手打、禁止口算后直接写；
3. 方法选择和每一次改主意都写进 `DECISIONS.md`——老师检查的首先是这两份 md。

## 开始分析的顺序

1. 数据放进 `data/raw/`；
2. 让 agent 加载 `method-selection-router`，回答五步法；
3. 按路由结果加载对应方法 skill（如 t-test）；
4. 跑分析，输出保存到 `output/`；
5. 过一遍该 skill 的「验证闸门」清单，全部打钩再写报告。
