# 实验报告模板

> 最少回答问题、方法及一句理由、真实输出来源与结果解释。按题目保留适用项，不要求填满全部模板。数字来自本次实际输出；SPSS允许准确转录并标表名/行列。未运行时写“未执行”，不填造结果。

## 一、分析目的

一句话说明问题、主要结局和要比较/估计的量。

## 二、资料与方法

- 数据来源、实验/抽样单位、实际n或完整对数、单位/编码、设计依据与缺失处理；
- 生效课程/通用规则、实际方法与理由、比较方向；调整分析说明目标与协变量；
- 软件及实际版本、必要算法（pooled/Welch、精确/渐近、校正与否）、预设α与单双侧、CI水平/算法。可引用DECISIONS和LOG，不重复抄写。

## 三、结果

### 1. 描述与必要检查

按资料给实际n、均数与SD，或中位数与四分位数、实际频数和分母；表按课程要求排版。只记本方法适用的分布、配对/实验单位或理论频数检查，不能由P>0.05宣称前提已证明。

### 2. 主要分析（选适用句式，按真实输出填写）

- **t检验**：`【方法】比较【目标】；均数差（B−A/后−前/均数−标准）=____【单位】，95%CI（____，____），t(df)=____，P=____。` 描述统计另给，d若使用须注明定义。
- **独立四格表Pearson/Yates**：`A组事件____/____，B组____/____；采用【未校正Pearson/Yates】，χ²=____，df=1，P=____；【A相对B、事件编码】的【RD/RR/样本OR等适用效应】=____，【置信水平与算法】CI（____，____）。`
- **Fisher双侧精确**：`两组实际频数____，Fisher双侧P=____；【方向】的【效应及算法】=____，CI____。` 不强填χ²/df；条件MLE OR与样本OR分别命名，不能混用区间算法。
- **R×C**：`各组类别分布____；【总体检验及适用统计量/df】、P=____。` 不预写“显著/不全相同”；如做预定事后比较，报告校正与实际结果。
- **配对二分类**：`完整对____，缺失对____；不一致b=____、c=____，方向____；McNemar【双侧精确二项/指定渐近法】，P=____。` 精确法不填Pearsonχ²/df；b+c=0单独说明。
- **简化配对对数等效界值教学演示**：`几何均值比及90%CI____；未舍入区间【满足/未满足】预设教学界值。` 本数据不据此完成正式BE评价。

效应与区间不依P是否显著而省略。零格或稀疏输入导致估计/区间未实现时，注明未估计及原因，不补造有限端点；空样本组发生率写“不适用”。

### 3. 来源与图表

给本次输出文件及表名/行列、页码或脚本字段，可复用LOG来源表。图注明实际n、单位及误差线是SD/SEM/CI。

## 四、解释与限制

依据实际P、效应和CI解释；P≥0.05不证明无差别或等效。观察性资料不越界作因果结论。专业标准缺失时不强判药典合格或“无专业意义”；药学结论说明依据。
