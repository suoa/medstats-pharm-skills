# 实验报告模板

> 正文数字一律来自 output/ 文件；统计表用三线表。

## 题目

## 一、分析目的

一句话写清要回答的问题。

## 二、资料与方法

- 数据来源、样本量 n、变量定义与单位；
- 统计软件与版本（SPSS / R / Python，版本号）；
- 方法选择依据：资料类型 + 设计类型 + 前提检查结论；
- 检验水准 α（默认 0.05）；双侧还是单侧。

## 三、结果

### 1. 统计描述

三线表：均数±标准差（或中位数+四分位数）、各组 n。

### 2. 前提检查

正态性、方差齐性等：检验名、统计量、P 值 → 结论（方法是否需要改）。

### 3. 假设检验

标准报告句式：
- t 检验：`两组 xx 分别为 a±b 与 c±d（n1=、n2=），差值 95%CI（…，…），t(df)=…，P=…（检验名称：独立样本 t 检验/Welch/配对 t）。`
- 卡方：`A 组阳性率 x%（n/N），B 组 y%，χ²(df,校正)=…，P=…，OR=…（95%CI…，…）。`

### 4. 图（如需要）

注明 n、误差线是 SD 还是 SEM。

## 四、结论

- 统计结论：拒绝/不拒绝 H₀；
- 专业结论：结合效应量与置信区间解释，P<0.05 不等于有专业意义，P≥0.05 不等于"无差别"；
- 局限性与改进。
